Parts

  • Seeed XIAO ESP32-C3 — one for the receiver, a second for the optional jammer — with the u.FL antenna that ships with it.
  • USB-C data cable (not charge-only) for the receiver; any USB-C power for the jammer.
  • Optional: two jumper wires (GPIO4 → D2, GND → GND) so the page’s Jammer button can switch the jammer on and off.

Things that bite

  • A loose u.FL shows only noise. Check the antenna before anything else.
  • Only one program can hold the receiver’s port: close any other SDR page or serial monitor.
  • Both boards are 3.3 V logic; the enable wire needs no level shifting. Don’t tie D0, D8 (SCK) or D9 (MISO) to ground at power-up on either board — those are ESP32-C3 strapping pins.
  • If the receiver won’t take new firmware: hold BOOT, tap RESET, release BOOT, then retry the installer.

Pinout detail is in wiring/wiring.md.

About this demo

What it shows, how to run it in front of a room, and how the signal gets from the air to the screen.

What it shows

Every ESP32 chip has a 2.4 GHz radio. This demo uses a hidden feature of that radio to grab the raw signal itself — not Wi-Fi packets, the actual waveform — and draw it three ways: a spectrum (how much energy at each frequency), a waterfall (that spectrum scrolling over time), and an I/Q scatter (the raw radio samples as dots, the thing a “constellation” is made of). It’s a real software-defined radio built from a $5 board.

Try this during the tour: point the center frequency at 2437 (Wi-Fi channel 6) and watch the hump grow when someone opens a video. Then hit Jammer and watch a sharp spike appear and the waterfall light up where the jammer node is transmitting.

Also try: tick Sweep and watch the jammer draw a diagonal down the waterfall; switch Trace to peak hold and wave a phone near the antenna; shift-click two markers either side of a Wi-Fi hump and read the difference; press P for the projector view.

How it works

radio front end → raw I/Q samples in the chip’s RAM → USB serial (CAP16 bursts) → this page runs an FFT and plots all three views. Nothing leaves your laptop; there’s no server. The firmware protocol is documented in ESP-SDR’s protocol.md, and this page’s client is in js/radio.js.

Known quirks:

  • Captures come in bursts with gaps between them — the sample rate (80 MS/s) describes one burst, not sustained throughput. That’s normal for the C3.
  • Power is in uncalibrated dBFS, not dBm. Good for “louder / quieter,” not for absolute measurements.

Put the firmware on the boards

The receiver takes ESPARGOS’s ESP-SDR build from their installer; the optional jammer takes a CircuitPython file from this page. Chrome or Edge.

Receiver — ESP-SDR

1. Open the installer

Go to the ESP-SDR browser installer. It flashes the stock build straight from the browser; nothing to install on your computer.

2. Plug in the XIAO

USB-C data cable. If the installer can’t find it, hold BOOT, tap RESET, release BOOT, and reconnect.

3. Flash the ESP32-C3 build

Pick the C3 target and let it write. firmware/VERSION.txt records the identity string this page was tested against (C3SDR 6 burst 16380).

4. Connect

Back on the instrument, click Connect board and pick the port named USB JTAG/serial (USB Serial Device on Windows). Type INFO in the serial log to see it answer.

The receiver runs ESP-SDR’s unmodified firmware; this repo doesn’t ship it. Flashing problems with it belong upstream.

Jammer (optional) — CircuitPython

1. Plug in

Connect the second XIAO ESP32-C3 over USB. If the instrument is connected to the receiver, this page disconnects it first.

2. Install

Click Install jammer and pick that board’s port. The page writes firmware/jammer/code.py over CircuitPython’s REPL, checks its size and CRC on the board, reboots it, and waits for its jammer ready line.

3. Move it

Antenna on, USB bank, a few feet from the receiver. Wire GPIO4 → D2 and GND → GND if you want the page’s Jammer button to switch it; otherwise set ALWAYS_ON = True in code.py before installing.

Ready. Plug the jammer board in and click Install.
No CircuitPython on that board. A XIAO ESP32-C3 fresh from the bag runs Seeed’s factory sketch, not CircuitPython. Install CircuitPython once with the button below, then come back to Install jammer. (The receiver board runs ESP-SDR and never needs CircuitPython.)

Doing the jammer by hand instead
  • Thonny: Tools → Options → Interpreter → CircuitPython (generic), pick the port, open firmware/jammer/code.py, then File → Save as… → CircuitPython device, name it code.py.
  • CircuitPython from a terminal: pip install esptool, then esptool.py --chip esp32c3 --port COMn erase_flash and esptool.py --chip esp32c3 --port COMn write_flash 0x0 adafruit-circuitpython-seeed_xiao_esp32c3-en_US-<version>.bin.
  • The REPL exchange the page uses is written out in PROTOCOL.md.
